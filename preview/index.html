  • ui calls services only — no file access (grep-verified)

08Deliberate behaviour & accepted warnings

By design (not defects)

  • Plain-text credentials — the coursework brief forbids external libraries.
  • Official tallies audit a Results generated entry; live dashboard counters use the silent preview tally.
  • Demo data is reseeded whenever a store file is missing or empty.
  • data/ resolves against the working directory — launch from the project root.
  • Voter-roll status shows VOTED (E002): one cached flag cannot encode several elections.

Residual lint warnings

  • 27 × [serial] — Swing frames hold service references and a row sorter; marking those fields transient would create a real null-after-deserialization defect.
  • 2 × [this-escape] in FileManager — the constructor’s demo seeder calls a public synchronized writer; making the class final would block the documented v2 storage subclass.
